(from control-inversion) Multi-phase construction (Watchers default-ctor → Init → SetMemoryOffset) is not enforced by the type system. Tests bypass this path with `BuildAllZero`.

(from test-skeptic) Tests pin scenarios rather than invariants. Composite conditions (ToExit, prevIO) are scenario-tested; truth-table coverage would catch boundary gaps. WatcherStateTests's hand-coded watcher list locks the test to schema.

(from dead-code) Several "abandoned feature" clusters: Mario-specific lives tracking, button monitoring, peach release, events triggered. None loaded by `UsedMemory()` — silently inert.

(from types) Tuple proliferation (Settings.entries) and string keys (Offset dicts) repeat without named types. EmuProfile's optional/nullable fields don't disambiguate "version-only" vs "direct-memory" vs "pointer-chain" emulator variants.

(from observability) SplitStatus blockers are separate from SplitReasons. A blocked-but-condition-true split returns false with no surface explanation of which gate fired. BlockedReasons exists but isn't tied to "would have fired".
